# Definition / User Guide

1. TODO, 실패, 재시도, 보류 항목을 다른 문서와 대화에 흩어 두지 않습니다.
2. 구현이 완료되고 검증되면 항목을 체크하고 Result/evidence 위치를 남깁니다.
3. 작업 중 Architecture 변경이 필요해지면 SWE3에서 임의로 확정하지 않고 SWE2로 되돌려 설계한 뒤 `ARCH.md`를 갱신합니다.
4. 단순 구현 상세는 완료 후 반드시 `ARCH.md`에 승격할 필요가 없습니다. Architecture/quality/interface/deployment/role contract에 영향을 주는 내용만 승격합니다.
5. 오래된 완료 항목은 Git history로 보존하면서 현재 baseline에서 정리할 수 있습니다.
